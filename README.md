Portofolio pribadi Ahmad Farizi, Fullstack Developer dari Universitas Madura. Menampilkan profil, proses kerja, dan proyek-proyek yang telah dirancang dan dikembangkan.

## Teknologi

- **HTML5** — Struktur halaman
- **Tailwind CSS** — Framework CSS utility-first (via CDN)
- **FontAwesome** — Ikon
- **Google Fonts (Inter)** — Tipografi

## Fitur

- Desain responsif (mobile & desktop)
- Efek glassmorphism pada kartu
- Navigasi smooth scroll
- Menu mobile interaktif
- Form kontak dengan notifikasi toast
- Animasi hover pada elemen interaktif

## Struktur Proyek

```
my_profile/
├── index.html      # Halaman utama portofolio
├── profile.png     # Foto profil
└── README.md       # Dokumentasi proyek
```

## Cara Menjalankan

1. Clone atau download repository ini
2. Buka file `index.html` langsung di browser, atau
3. Gunakan live server (misal: Live Server di VS Code) untuk pengembangan
